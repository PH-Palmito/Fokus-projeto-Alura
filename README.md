
# ⏳ Fokus - Pomodoro + To-Do List

**Fokus** é um projeto criado com o objetivo de treinar a manipulação de elementos no **DOM com JavaScript puro**. Ele combina um **cronômetro Pomodoro** com uma **lista de tarefas (To-Do List)** — ideal para quem quer estudar ou trabalhar com mais foco.

🔗 **Acesse o projeto online:**  
[https://ph-palmito.github.io/Fokus-projeto-Alura/](https://ph-palmito.github.io/Fokus-projeto-Alura/)

---

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## 🎯 Objetivo do Projeto

Praticar lógica e manipulação do DOM, construindo uma interface funcional que ajude no foco e na organização do dia a dia.

---

## ⚙️ Funcionalidades

- ⏲️ Timer estilo Pomodoro (foco, descanso curto e longo)
- 📝 To-Do List integrada
- ✅ Marcar tarefas como feitas
- 🔄 Reinício e pausa do cronômetro
- Interface dinâmica com interações via DOM
